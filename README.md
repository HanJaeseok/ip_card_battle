# 🐑🧜‍♀️🐰🐯 한국특허정보원 카드배틀

10×10 보드 위 아기 동물 카드 짝 맞추기를, 4대 지식재산권(실용신안·상표·디자인·특허)의 성격을 체화한 특수 능력으로 재해석한 실시간 N:N 팀 대전 웹 게임입니다.

- 🐑 **실용신양** (실용신안 + 양) — 질보다 양, 점수가 쌓일수록 한 번에 더 많은 카드가 연쇄로 열림
- 🐰 **상표토끼** (상표 + 토끼) — 임계값 돌파 시 현재 턴수에 비례한 보너스 획득
- 🧜‍♀️ **디자인어** (디자인 + 인어) — 뒤처지면 상대 점수를 흡수해 캐치업, 앞서면 소량 보너스
- 🐯 **특허랑이** (특허 + 호랑이) — 임계값 돌파 시 상대의 실용신양·상표토끼 점수를 강하게 깎는 공격

게임 규칙과 밸런스 수치의 상세 내역은 [`ROADMAP.md`](./ROADMAP.md)를 참고하세요.

## 기술 스택

- **클라이언트**: Next.js (App Router) + TypeScript + Tailwind CSS
- **서버**: Node.js + WebSocket (`ws`) — 게임 상태의 유일한 진실(Source of Truth)
- **공유**: `/shared` — 타입·상수·WebSocket 프로토콜 (클라이언트·서버 공용)

핵심 설계 원칙:
- 미오픈 카드의 동물/숫자는 어떤 경우에도 클라이언트로 전송하지 않음 (치팅 방지)
- 모든 랜덤(강제진행, 실용신양 추가 오픈, 보드 확장 배치)은 서버에서 생성
- 30초 턴 타이머는 서버가 `turnDeadline` 타임스탬프로 관리, 클라이언트 타이머는 표시 전용

## 디렉토리 구조

```
card_battle/
├── shared/          # 타입·상수·WebSocket 프로토콜 (양쪽에서 공유)
├── server/          # Node.js 게임 서버 (WebSocket, 룸 관리, 게임 엔진)
│   └── engine/      # 순수 게임 로직 (UI와 완전 분리, 단위 테스트 대상)
└── client/          # Next.js 앱 (로비·게임 화면·애니메이션)
```

## 시작하기

터미널 두 개를 열어 각각 실행합니다.

```bash
# 터미널 1 — WebSocket 게임 서버 (포트 8080)
cd server
npm run dev

# 터미널 2 — Next.js 클라이언트 (포트 3000)
cd client
npm run dev
```

브라우저에서 `http://localhost:3000` 접속 후, 방을 만들고 다른 브라우저(또는 시크릿 창 — 같은 브라우저의 새 창은 세션 정보를 공유해 충돌합니다)로 참가하면 대전을 시작할 수 있습니다.

### 환경 변수

| 항목 | 기본값 | 변경 방법 |
|---|---|---|
| WebSocket 서버 포트 | `8080` | `PORT=9000 npm run dev` |
| Next.js 포트 | `3000` | `npm run dev -- -p 3001` |
| 클라이언트가 바라보는 WS 주소 | `ws://localhost:8080` | `NEXT_PUBLIC_WS_URL` 환경 변수 |

## 테스트

```bash
cd server
npm test          # 단위 테스트 (규칙 케이스 + 봇 시뮬레이션)
npm run test:sim  # 봇 500게임 시뮬레이션 (밸런스 검증)
```
